# 成片库吸睛画面文案（用户旧称“旁白”）

## 输入与文案

每个新前贴方案在脚本阶段先写三句候选，作为独立的“吸睛画面文案（无声备选）”放在 Seedance 提示词代码块之外；每句不超过28字，配各自的黄色重点词、红色反转词，词语须为该句原文。候选只依据当前方案已知剧情，不虚构未核实的画面、人物或结局。它们不是对白、配音或 Seedance 画面指令。

成片库只使用已获授权、可播放的最终视频作为底片。打开文案面板就显示三句带中文引号的候选：优先使用脚本预生成文案，其次复用此前按片头草拟的缓存；都没有时仅按剧名显示基础候选，须明确标注“尚未核对剧情”。用户可手动调用 Codex 按真实片头重新草拟三句，此步消耗 Codex 额度，不调用付费视频模型。对每句都核对片头画面、原声、重点词和展示时码；不能把仅依剧名的基础候选表述为已核实剧情。

## 画面与原声

用户示例中的红框只是标注，不进入成片。默认在画面左下角显示最多两行引号内文案：白色粗体、清晰黑描边，可把文案中各一段原词设为黄色重点和红色反转，不在重点词中间断行；位置与尺寸按横竖屏安全区自适应，不盖原字幕、人物关键表情或剧名。只加文案时原成片不裁剪、总时长与原音轨不变。多选批量时每句产出一条，按候选顺序使用 1.0、1.1、1.2 倍速；变速版对完整视频与原音同步变速并尽量保持音高，时码按倍速换算，不随意重裁钩子或切断一句对白。不同字幕和轻微变速不等于平台判定的独立素材，不能保证去重效果。禁止 TTS、画外音、原声压低或新增人物对白。

## 时码与验收

画面文案默认从片头出现，最晚在第10秒消失；有原字幕时间时可建议与原台词收束点一起消失，变速后先换算再实看核对，不能把估计说成精确同步。文案全文在指定区间稳定显示，不跟随人物说话逐字跳动；对白原字幕照旧。导出后逐条核对文案可读、两行不越界、强调色与错字、消失帧、变速音画同步、原片结尾对白完整；未实看只能称预览版，不能称验收通过。

## 工作台使用与状态

本机工作台入口是“成片库 → 剧名 → 具体成片 → 给这条成片加吸睛文案”。候选立即显示，逐句带“”；可勾选多句后点击“生成已选文案视频”，一条文案对应一条成片。单选时可先编辑文字及黄色/红色重点词；多选按列表原文分别合成。每条生成后都单独预览、下载、查看本地文件夹，并归入同剧“吸睛画面文案版”；原成片保留，不调用 Seedance 或配音服务。历史“旧版配音旁白”记录可继续查看，但不作为此模式模板。共享 Skill 只提供规则，同事是否具备该工作台功能须另核对程序版本。

# 成片库吸睛画面文案（用户旧称“旁白”）

## 输入与文案

每个新前贴方案在脚本阶段先写三句候选，作为独立的“吸睛画面文案（无声备选）”放在 Seedance 提示词代码块之外；每句不超过28字，配各自的黄色重点词、红色反转词，词语须为该句原文。候选只依据当前方案已知剧情，不虚构未核实的画面、人物或结局。它们不是对白、配音或 Seedance 画面指令。

成片库只使用已获授权、可播放的最终视频作为底片。优先显示该方案预生成的候选，但仍须核对片头真实画面和原声；脚本与成片不符时修改或重新草拟。旧素材没有预生成文案时，选中成片后可调用 Codex 草拟三句；此步消耗 Codex 额度，不调用付费视频模型。用户选中或修改其中一句，再核对关键词、展示起止秒数。

## 画面与原声

用户示例中的红框只是标注，不进入成片。默认在画面左下角显示最多两行引号内文案：白色粗体、清晰黑描边，可把文案中各一段原词设为黄色重点和红色反转，不在重点词中间断行；位置与尺寸按横竖屏安全区自适应，不盖原字幕、人物关键表情或剧名。原成片不裁剪，总时长和原音轨保持不变；禁止 TTS、画外音、原声压低或新增人物对白。

## 时码与验收

画面文案默认从片头出现，最晚在第10秒消失；有原字幕时间时可建议与原台词收束点一起消失，但必须实看核对，不能把估计说成精确同步。文案全文在指定区间稳定显示，不跟随人物说话逐字跳动；对白原字幕照旧。导出后核对文案可读、两行不越界、强调色与错字、消失帧、原声音轨保留；未实看只能称预览版，不能称验收通过。

## 工作台使用与状态

本机工作台入口是“成片库 → 剧名 → 具体成片 → 给这条成片加吸睛文案”。新前贴会直接带出脚本阶段的三句候选；旧素材或用户要换稿时再草拟。候选可选一条并修改文字、黄色/红色重点词和展示起止秒数。输出归入同剧“吸睛画面文案版”，原成片保留；不调用 Seedance，也不调用配音服务。历史“旧版配音旁白”记录可继续查看，但不作为此模式模板。共享 Skill 只提供规则，同事是否具备该工作台功能须另核对程序版本。

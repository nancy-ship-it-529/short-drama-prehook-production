# 原片 / 已完成前贴的旁白制作

## 输入与文案

只使用已获授权、可播放的本地原片或成片库中已完成的 AI 前贴作为底片。先看片头和旁白预计覆盖区间，确定一句旁白讲的是实际剧情而非凭简介臆测；不要虚构未出现的反转或误导观众。剧名概括、身份反差和危机钩子可作为文案方向，但以画面和原声为准。成片库选中一条已完成视频后，工作台调用 Codex 草拟三句候选；此步消耗 Codex 额度但不生成视频。用户选中或修改一整句，再核对进入时码与音色并合成试听。

## 声音与画面

底片画面和总时长保持不变，不裁原片、不替换人物对白。旁白是画外音，不驱动人物口型。旁白时段短暂压低底片原声，结束后恢复；如果会盖住关键对白，调整旁白起点或重写更短文案，不能直接盖掉原句。成片库旁白的实际发声须在片头第10秒之前完整结束；有原字幕时间时可据此建议原台词的收尾秒数，但仍需实听核对，不得声称精确同步。文案念不完就停止并提示缩短，不截断尾音。内置合成会把旁白文案送往语音服务，不等同 Seedance 人物原声。

## 字幕与验收

旁白字幕为可选项，不应与底片已有字幕叠在同一位置。只有取得与逐字文案一致的发声边界时才能自动烧录；旁白文字在对应发声结束时消失，不为了凑满10秒继续留屏。长句缺少可靠分句时码时先不烧录，留待人工对齐。试听时核对首字起声、尾音结束、原台词是否被盖住、音量恢复、字幕位置与错字；未实听实看仅称“试听版”，不能称人工验收通过。

## 工作台使用与状态

本机工作台入口是“成片库 → 剧名 → 具体成片 → 给这条成片加旁白”，不是独立旁白页。选择三句候选之一，可改文案、起声和最晚结束秒数、音色及是否加旁白字幕。现有字幕可给出不晚于10秒的收尾建议，需人工试听；合成后在同剧“旁白版”查看、下载，原成片仍保留。不调用 Seedance 重生画面，也没有 Seedance 生成费；合成音色依赖当前 TTS 服务可用。共享 Skill 只提供规则，同事是否具备该工作台功能须另核对程序版本。

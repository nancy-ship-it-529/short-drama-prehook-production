# 原片 / 已完成前贴的旁白制作

## 输入与文案

只使用已获授权、可播放的本地原片或成片库中已完成的 AI 前贴作为底片。先看底片开头和旁白预计覆盖区间，确定一句旁白讲的是实际剧情而非凭简介臆测；不要虚构未出现的反转或误导观众。剧名概括、身份反差和危机钩子可作为文案方向，但以画面和原声为准。工作台可调用 Codex 草拟三句候选，此步消耗 Codex 额度但不生成视频；用户选中或修改文案后，再核对进入时码与音色并合成试听。

## 声音与画面

底片画面和总时长保持不变，不裁原片、不替换人物对白。旁白是画外音，不驱动人物口型。旁白时段短暂压低底片原声，结束后恢复；如果会盖住关键对白，调整旁白起点或重写更短文案，不能直接盖掉原句。文案超出底片剩余时长时停止并提示，不截断尾音。可使用合成旁白或用户自带、已授权的配音文件；自带文件优先保留其自然情绪。内置合成会把旁白文案送往语音服务，不等同 Seedance 人物原声；敏感文案可改用本地自带音频。

## 字幕与验收

旁白字幕为可选项，不应与底片已有字幕叠在同一位置。只有取得与逐字文案一致的发声边界时才能自动烧录；长句缺少可靠分句时码时先不烧录，留待人工对齐。若使用自带旁白音频但没有可信词级时码，不自动生成字幕。试听时核对首字起声、尾音结束、音量压低和恢复、字幕位置与错字；未实听实看仅称“试听版”，不能称人工验收通过。

## 工作台使用与状态

本机工作台有独立“旁白制作”页，可选成片库已完成前贴，或填本地原片路径；输入剧名、文案、起声秒数、音色/自带音频，选择是否加旁白字幕。点击合成后生成本地试听版，可在“成片库 → 剧名 → 旁白版”查看、下载。不调用 Seedance 重生画面，也没有 Seedance 生成费；合成音色依赖当前 TTS 服务可用，失败时保留底片并可换自带配音文件。共享 Skill 只提供规则，同事是否具备该工作台功能须另核对程序版本。
